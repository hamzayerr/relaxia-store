# Google Sheets Integration

## Overview

Orders are sent to a Google Sheet via Google Apps Script webhook (Web App URL).  
No authentication secret — just the deploy URL (security by obscurity, sufficient for COD orders).

## Google Apps Script Code

Create `sheets/google-apps-script-webhook.js`:

```javascript
// Google Apps Script — RELAXIA Order Webhook Receiver
// Deploy as: Web App → Execute as: Me → Who has access: Anyone

const SHEET_NAME = "Orders";

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    appendOrderToSheet(data);
    return ContentService
      .createTextOutput(JSON.stringify({ success: true, orderId: data.orderId }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ success: false, error: error.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function appendOrderToSheet(data) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME);
  
  // Create sheet if it doesn't exist
  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
    // Add headers
    sheet.appendRow([
      "Order ID", "Date", "Country", "Name", "Phone", "City",
      "Product", "SKU", "Quantity", "Total Price", "Currency", "Status"
    ]);
    // Style header row
    const headerRange = sheet.getRange(1, 1, 1, 12);
    headerRange.setBackground("#0B4D2E");
    headerRange.setFontColor("#FFFFFF");
    headerRange.setFontWeight("bold");
    sheet.setFrozenRows(1);
  }
  
  // Append order row
  sheet.appendRow([
    data.orderId || "",
    data.date || formatDate(new Date()),
    data.country || "Morocco",
    data.name || "",
    data.phone || "",
    data.city || "",
    data.product || "",
    data.sku || "",
    data.quantity || "",
    data.totalPrice || 0,
    data.currency || "MAD",
    data.status || "",   // empty — filled manually
  ]);
  
  // Auto-resize columns for readability
  sheet.autoResizeColumns(1, 12);
}

function formatDate(date) {
  const d = date.getDate().toString().padStart(2, '0');
  const m = (date.getMonth() + 1).toString().padStart(2, '0');
  const y = date.getFullYear();
  return `${d}/${m}/${y}`;
}

// Optional: Test function to run manually
function testWebhook() {
  const testData = {
    orderId: "RLX-20260519-TEST",
    date: "19/05/2026",
    country: "Morocco",
    name: "محمد الأمين",
    phone: "0612345678",
    city: "الدار البيضاء",
    product: "كولوفلورا/بيلوريكس",
    sku: "RLX-COL-30/RLX-PYL-30",
    quantity: "2/1",
    totalPrice: 574,
    currency: "MAD",
    status: "",
  };
  appendOrderToSheet(testData);
  Logger.log("Test order added successfully");
}
```

## Deployment Instructions

### Step 1: Create Google Sheet
1. Go to [sheets.google.com](https://sheets.google.com)
2. Create new spreadsheet named "RELAXIA Orders"
3. You can leave it empty — the script creates the "Orders" sheet with headers automatically

### Step 2: Open Apps Script
1. In the Sheet: Extensions → Apps Script
2. Delete the default `myFunction` code
3. Paste the entire `google-apps-script-webhook.js` content
4. Save (Ctrl+S) — name project "RELAXIA Webhook"

### Step 3: Deploy as Web App
1. Click Deploy → New deployment
2. Select type: **Web App**
3. Configuration:
   - Execute as: **Me** (your Google account)
   - Who has access: **Anyone** (no auth needed)
4. Click Deploy
5. **Copy the Web App URL** — it looks like:
   ```
   https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/exec
   ```

### Step 4: Add to Backend Environment
```env
# In backend/.env (and EasyPanel env variables)
GOOGLE_SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec
```

### Step 5: Test
Run the `testWebhook()` function from Apps Script editor to verify a row appears in the sheet.

```json
  "country": "Morocco",

  "sku": "RLX-COL-30/RLX-PYL-30",
  "quantity": "4/1",
  "totalPrice": 574,
  "currency": "MAD",
  "status": ""
}
```

### Multi-Product Quantity Format
```
If order has:
  - COLOFLORA × 2-pack bundle × 1 quantity → 2 pieces → "2"
  - PYLOREX × 1-pack bundle × 1 quantity → 1 piece → "1"
  
quantity field = "2/1"
product field = "كولوفلورا/بيلوريكس"
sku field = "RLX-COL-30/RLX-PYL-30"
```

## Backend Service: sheets.py (Full Implementation)

See [docs/09-backend-api.md] — services/sheets.py for complete async implementation with:
- 3 retry attempts with exponential backoff
- Error logging to database (`sheet_error` column)
- Non-blocking (runs as FastAPI BackgroundTask)
- Marks `sheet_synced = true` on success

---

## Error Recovery

If sheet sync fails (network issue, Apps Script down):
1. Backend logs error to `orders.sheet_error`
2. Backend marks `orders.sheet_synced = false`
3. Admin dashboard shows "Sheets Sync Failed" badge on affected orders
4. Admin can manually trigger re-sync from dashboard
5. A daily cron job (optional) can retry all unsynced orders

### Manual Retry Endpoint
```
POST /api/admin/orders/{order_id}/sync-sheet
Authorization: Bearer {admin_token}
```
